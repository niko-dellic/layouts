The full Quilt showcase as an offline desktop app. Includes both vanilla and React demos, native companion windows, themes, resizing, and workspace JSON. No Node.js or terminal setup is needed.

## Downloads

- **macOS Apple Silicon:** `mac-arm64.dmg`
- **macOS Intel:** `mac-x64.dmg`
- **Windows 64-bit:** `win-x64.exe` (portable app)
- **Ubuntu / Debian 64-bit:** `linux-amd64.deb`

On macOS, open the DMG and drag Quilt Demo into Applications. On Windows, open the EXE. On Ubuntu / Debian, open the DEB with your software installer, then launch Quilt Demo from the applications menu.

These are unsigned demo builds. macOS or Windows may show an unidentified-developer warning. macOS may require approval in System Settings → Privacy & Security after the first attempt to open the app. Windows may offer More info → Run anyway. Managed devices may prohibit unsigned applications. No signing certificate or notarization is included.

Closing a companion returns its pane. Saved workspaces restore docked. Application state persists across pane moves and popouts within a session; this showcase does not promise persistent user data between app launches.

SHA-256 checksums are provided alongside the downloads.
